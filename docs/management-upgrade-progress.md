## 本轮收尾修正与审查

- Provider 统计返回配额预留的数据库日期，跨午夜完成写回同一天；预留后取消保守计入配额。
- 原文清理先锁终结任务，再删明细；重试在同一任务锁内检查原文。清理只选仍有明细的任务，避免每次重复选择已清理的前 100 个任务。
- 导入每条记忆与明细断点一起提交；任务故障或关闭不以领取任务时的旧快照覆盖已提交进度。
- 贡献者可为自己导入的记录完成向量生成，不借此获得对他人记录的编辑权限。测试断言 Provider 调用及 `ready` 向量写入；取消或生成失败仍可能需要管理员后续重建。
- CSP 在哈希前统一 CRLF/CR 为 LF，与浏览器 HTML 解析一致；新增换行符回归。
- Nginx 精确匹配导出路由，关闭缓冲并设置 120 秒读写超时。
- 静态复核迁移 `016` 与记忆/导入/成员/邀请/配额事务：涉及空间及其子记录的主要写入入口先锁空间，再处理记忆、任务或邀请；导入清理/重试只锁任务及明细。静态检查不能证明真实 PostgreSQL 并发行为，相关验收保持未勾选。
- 原同步导入和 MCP 接口保留；历史无原文导入不能重试。新页面永久删除要求先入回收站，旧 `memory_forget(permanent=true)` 仍保留管理员直接永久删除的兼容语义。
